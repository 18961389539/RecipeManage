## 易用性第五批：全站共享层（http / router / 外壳）
- 前 5 轮都是**页面级**修补，这一轮集中在**所有页面共用的出口层**——一处修全站受益。
- **401 会话过期**（`api/http.ts` + `main.ts`）：原先 `location.assign("/login")` 整页重载，把用户填了一半的
  表单一起丢掉、且无任何原因说明。改为导出 `reportSessionExpired(fn)` 由 main.ts 注入应用内跳转 + ElMessage.warning。
  - **不要在 http.ts 里 import router**：http ← stores/auth ← router 已成环。回调注入是唯一干净出口。
  - **并发去重**：各列表页 4s 轮询，token 过期是多个请求同时 401；用 `expiredHandled` 标志只提示一次，
    任意一次 2xx 响应复位（登录成功天然复位）。实测 12 个并发 401 只出 1 条提示。

  防开放重定向：只接受 `/` 开头**且非 `//` 开头**（`//evil.com` 在浏览器眼里是绝对 URL）。
  token 15 分钟过期，这条路径是真实高频的。
- **404 兜底**：新增 `views/NotFound.vue`，`path: ":pathMatch(.*)*"` **挂在 AppShell 之下**（保留侧边栏可改道）。

- **标题单一来源**：每条路由补 `meta.title`；AppShell 顶栏与 `router.afterEach` 的 `document.title` 都读它。
  删掉 AppShell 里 `route.path.startsWith(...)` 的硬推链——详情页此前只能落到所属大类名上。
- **权限跳转加解释**：无权访问仍跳 `/dashboard`（`e2e/ops-shopfloor.spec.ts` 断言的是 URL，不变），

## 配色第二轮：令牌收敛 + 可访问性修
用户选的口径是「令牌收敛 + 可访问性修」，即观感基本不动、把散落的色值收进令牌并修掉对比度不达标项。

### 色板唯一数据源
- `styles.css` 的 `:root` 现在是**全站唯一取色点**。此前 15 个视图/组件里散着 116 处硬编码 hex，
  其中 8 个是语义重叠的近似蓝黑（#0f1728/#131c30/#152038/#16203a/#17203a/#1a2740/#1d2b4a/#1d3a63）。
  现在全部收敛成四档表面令牌：`--sunken`（输入框/侧栏/画布等凹区）、`--raised`（表头/工艺节点/控制条）、
  `--hover`、`--tint`（选中底）。另有 `--text-body`、`--accent-bright`（选中态文字，比 --accent 亮一档给小字用）、
  `--idle`（未激活连线/默认状态点）、`--cool`、`--violet`、`--scrollbar*`。
- **`--accent-rgb` 必须空格分隔**：`rgb(var(--accent-rgb) / .35)` 的斜杠写法不接受逗号。辉光类（StepFlowNode）用它拼透明度。
- 组件里一律 `var(--x)`，**不要再落 hex**。唯一保留的字面量是 `BatchRecord.vue` 打印样式里的 `.ebr { color: #111 }`（纸面用深色，故意的）。
- **canvas 图表读不到 var()**：ECharts / uPlot 拿的是 JS 对象，只能运行时解析。走 `src/utils/theme.ts` 的
  `palette('--text-body')`（内部 `getComputedStyle(document.documentElement).getPropertyValue`），别把 hex 再抄回图表配置里。

### Element Plus 暗色主题的色阶方向（本轮最大的一个坑）
- 暗色主题下 `--el-color-xx-light-N` 是**与 #141414 按 N×10% 混（越 light 越暗）**，`dark-2` 才是往白混。
  此前 primary 的 light-N 照抄了浅色主题取值，`light-9 = #ecf5ff` 近乎纯白；
  而 el-table 当前行底色正是 `primary-light-9` → 审核页选中行浅底压浅字，实测 **1.32:1**。
- **只改 `--el-color-success` 一个变量不够**：tag / button / alert 各组件取的是 light-3/5/7/8/9 与 dark-2 整条阶梯，
  漏掉哪一档，那个交互态就跳回 EP 默认色。本轮五套状态色（primary/success/warning/danger+error/info）阶梯全部重写。
- 覆盖优先级：`html.dark .xxx` 是 (0,2,1)，压过 EP 的 `.el-tag--dark.el-tag--success` (0,2,0)，**不需要 !important**。

### 亮底压白字 = 本项目的系统性缺陷，统一用「深色墨水」解
状态色本身偏亮（#3dd68c/#f5c84c/#ff6b6b），EP 在这些组件里把文字硬设成白色 → 12px 小字只有 1.6~3.3:1。
改成 `var(--bg)` 墨水印后同样的底能到 5.6~11.8:1。已收口的四处：
- `html.dark .el-tag--dark { --el-tag-text-color: var(--bg); }`
- `html.dark .el-radio-button { --el-radio-button-checked-text-color: var(--bg); }`
- 实色按钮：五种 type 一条规则，`--el-button-text-color/hover/active` 全给墨水，
  **hover 底用 `color-mix(in srgb, var(--el-button-bg-color) 85%, white)` 往亮提一档**（EP 默认往暗混，墨水在暗底上会掉到 3.3:1），
  active 回到底色。引用 `--el-button-bg-color` 就不必为每种 type 各写一遍。
  - 选择器**必须** `:not(.is-plain):not(.is-text):not(.is-link)`：plain/text/link 的文字色本应等于主色，被覆盖就隐形。
- `.dot` 默认色、`--el-text-color-placeholder`（原 #6b7fa3 在凹底 4.47:1 → #7c90b4）。
- **禁用态按 WCAG 1.4.3 豁免**，不要为它调配色；对比度扫描脚本要跳过 `.is-disabled`，否则满是假阳性。

### 批次状态语义
- `Running → primary`（蓝）：绿色留给好终态，且工步级 `stepOutcomeTagType` 早就是 Running→primary，两级口径此前不一致。
- `Completed → success`（绿）：用户明确要「完成改绿」。注意它的 UI 文案是「待放行」，而 `Released`（已放行）也是绿——
  列表里两枚绿标签靠文字区分。**若 QA 反馈误读，一行回退**（labels.ts 的 batchStatusTagDict）。
- `Queued` 与 `Held` 仍是 warning 黄，二者都是"需人处理的暂停/等待"，暂时不拆。
